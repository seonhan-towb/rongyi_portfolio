# 구현 기준과 검증 기록

기록일: 2026-10-28

## 기준 버전

| 구분 | 기준 |
|---|---|
| 구현 설명 | Android 앱 `develop` |
| 화면 캡처 | `0.0.8(104)`, Rel Debug (운영 API) |
| 실행 환경 | Android 에뮬레이터, 디바이스 |
| 배포 상태 | 앱 Google Play 배포 |

최신 캡처는 공통 상단 타이틀, 챕터 목록, 학습 완료, 목표 변경 제목, 설정 카드 높이를 수정한 앱으로 전체 20장(라이트 14장, 다크 6장)을 다시 촬영했습니다. `:app:installRelDebug` 빌드와 에뮬레이터 설치가 통과했으며 운영 API(`https://api.towbstudio.com/`)에 연결했습니다. 구현 상세 문서는 `develop` 커밋을 기준으로 작성했습니다.

## 기존 자동 검증

| 항목 | 결과 |
|---|---|
| `:app:compileDevDebugKotlin` | 통과 |
| `:app:testDevDebugUnitTest` | 16개 통과, 실패, 오류, 건너뜀 0개 |
| 캡처용 `:app:assembleDevDebug` | 통과 |

이 결과는 해당 빌드, 테스트 범위의 확인이며 모든 학습 시나리오를 포괄하는 지표는 아닙니다.

## 화면을 실행하며 확인한 흐름

| 흐름 | 확인 내용 |
|---|---|
| 화면 모드 | 설정에서 라이트, 다크 전환 및 주요 화면 표시 |
| 홈,목표 | 학습 기록 표시, 목표 변경 시트 진입 |
| HSK 선택 | 레벨과 챕터 펼치기, 챕터 진입 |
| 단어 학습 | 카드 뒤집기, 뜻, 예문 번역, 예문 속 단어 강조 |
| 단어 완료, 복습 | 30개 학습 후 선택한 단어 1개의 완료 목록과 복습 진입 |
| 패턴 문제 | 패턴, 한국어 뜻 표시와 조각 드래그 |
| 패턴 오답 | 다른 순서로 배열해 제출한 뒤 완료 화면에서 내 답과 정답 비교 |
| 오답노트, 결과 | 오답노트 이동 후 완료 목록과 내 답, 기준 답 펼치기 |
| 패턴 복습 | 같은 문제를 기준 순서로 배열, 제출한 뒤 모두 정답 화면 표시 |
| 저장 공간 | 캐시 용량과 삭제 범위 선택 시트 표시. 이번 재촬영에서는 삭제를 실행하지 않음 |

오답노트와 관련한 내용으로 단어의 기억 여부는 `다시 볼래요` 선택으로 기록합니다. 패턴의 `오답노트로` 선택으로 기록 합니다.

## 추가 확인

- 빠른 연속 터치에서 완료 화면이 한 번만 열리고 결과가 유지되는지
- 화면 회전,재생성,프로세스 복원 후 완료 결과와 학습 진행이 유지되는지
- 온라인,오프라인 전환과 재접속 시 채점,캐시가 정책대로 동작하는지
- 서버 콘텐츠 버전 변경과 상태 API 실패 후 갱신이 정상인지

## 이미지와 문서 관리

최신 캡처는 `assets/screenshots/light/`, `dark/`에 보관합니다.

문서 정리 시 로컬 링크와 이미지 경로의 존재 여부를 검사합니다. 공개 자료는 서비스 소개,구현 근거,실행 결과,향후 계획을 구분하며 사용자 수나 학습 효과를 측정 성과로 주장하지 않습니다.
